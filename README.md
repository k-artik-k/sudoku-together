# Sudoku Together
 
Real-time multiplayer Sudoku for friends. Create a room, share the code, and solve one puzzle together, live. No accounts, no limits.
 
## Features
 
- Rooms for 2 to 4 players, joined with a 4-letter code or an invite link
- One shared board with every player's digits in their own color
- Easy, medium, hard and expert puzzles, as many as you want
- Pencil notes, hints and unlimited mistakes
- Light and dark theme, made for both phone and desktop
## Built with
 
Cloudflare Workers, Durable Objects, WebSockets and plain JavaScript.
